# Automated Web Testing Project

## Summary
For this project, the site that you will be testing is https://automationexercise.com/.
This is an example of a website that has been created specifically for practicing automation coding.
Your TASK is to look at the functionality for the website, derive user stories from this and
create some test cases for said user stories.
Your project will be 1 sprint in length

## Planning
You will need to create a sprint backlog of all user stories (which correspond to Gherkin features) on your project board (use Trello or GitHub).

![Example Github Project Board](./media/Github%20Project%20Board.png)

If you do find any defects, convert the ticket into an issues and place into the issue column. Add a description about that the issue:

![Github Issue Template](./media/Github%20Issue.png)

## Deliverables
- [ ] Up-to-date project board
- [ ] High quality user stories and test cases
- [ ] Fully functional test framework using POM pattern
- [ ] Gherkin scenarios that represent the user journeys
- [ ] A README file which includes:
   - The goal of the project
   - How to set up your test framework
   - What was tested
    - Test Metrics
- [ ] Collaborative use of GitHub (you will need to investigate how to do this)
- [ ] Defect reports (you will need to investigate the information required for these)
- [ ] Exploratory Test Charters
- [ ] At least one GitHub Action Workflow
- [ ] Present your work at 10:45am on Monday 13th July - everyone in the group must participate, your presentation is to last for a maximum of 10 minutes
    
## What to include in presentations
- Overview of what you will be covering
- What is the system under test?
- Example user journey (manual and automated)
- Number of tests and percentage passed (including manual)
- Brief description defects and suggested actions
- Brief overview of the framework
- Brief overview of project organisation (project board, readme, test approach)
- Retro/ lessons learned
